# SOP-QA-02: Incoming Pulp Qualification

## Purpose
Control the risk of quality changes when pulp lots or suppliers change.

## Rules
- Every new supplier must pass a laboratory bleachability trial before full-scale use.
- First full-scale use of a new supplier must be announced to the bleach plant and quality lab.
- Run the first lot of a new supplier for at most one day, then review brightness results.

## Why it matters
Different fibre sources respond differently to the same bleaching conditions. A pulp with poor
bleachability lowers brightness even when every process variable is on target. In that case the
process data looks normal and only the material change explains the quality drop.

## Investigation
If brightness falls with no process deviation, check the events log for material changes and the
pulp lot / supplier of the affected batches.
