# SOP-RCA-00: Root-Cause Analysis Method

## Evidence standard
A root cause is accepted only when it is supported by at least two independent kinds of evidence:
1. **Data**: an abnormal process variable, with the right direction and timing.
2. **Timing**: the cause precedes the effect with a physically plausible delay.
3. **Records**: a maintenance log, operator note, alarm or material change that explains it.

Correlation alone is not proof. A variable that correlates with the symptom but shows no anomaly,
no plausible delay and no supporting record is a coincidence until shown otherwise.

## Avoid common mistakes
- Do not blame the event closest in time without a physical link (red herrings).
- Do not treat an alarm as a process problem until the sensor is verified.
- If no process variable deviated, look at materials and external changes.

## Report format
Problem statement, affected batches, root cause, evidence (data / timing / records), confidence
(high / medium / low), corrective actions, preventive actions.
